# 后台管理员账号

首次启动且初始账号不存在时，自动创建超级管理员 `admin`，默认密码 `admin1234`。
`ADMIN_INITIAL_USERNAME` / `ADMIN_INITIAL_PASSWORD` 可覆盖首次初始化值。已有账号和密码不会被重启或发布覆盖。

超级管理员进入「角色管理」新建角色并勾选功能权限，再进入「账号管理」新增子管理员、设置密码并分配角色。
同一角色的账号共享权限；如需不同权限，创建不同角色。权限按现有后端功能点生效，修改后下一次请求立即生效。

「账号管理」支持编辑姓名、变更子管理员角色、启停子管理员，以及重置密码（留空保持不变）。
账号或角色变更、密码重置会使该账号旧令牌失效；角色权限修改不会要求重新登录，但界面需刷新以更新菜单。
超级管理员不能被停用或降级，其角色不能被修改或删除。子管理员不能管理账号或修改角色，即使为其勾选角色写权限也不会开放这些操作。
密码只保存 bcrypt 哈希，接口和操作日志不返回密码或哈希。本功能无需数据库结构迁移。
