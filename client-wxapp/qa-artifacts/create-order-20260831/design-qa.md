# 创建预约改版验收

依据：用户提供的 Ardot C5 截图（服务双列、横向日期、时段、服务地址）以及入口规则。

- 普通入口：多位美甲师需手动选择，唯一美甲师自动选中且重复点击不重置。
- 指定入口：锁定美甲师；同款使用作品卡，其余入口选择服务。
- 服务卡使用中性色令牌，选中黑底白字。保留真实报价、时长和自定义需求。
- 日期组件增加可选横向呈现，保留月份切换，复用停单、占用、营业时间与服务时长校验；其他调用方保留原日历。
- 到店形式与门店地址合并为单选卡；切换门店清空旧时段，重复点击当前门店保留时段。
- 底部保留安全区，价格与提交操作同排。

自动检查：入口场景测试、现有预约时段与门店测试、发布门禁和颜色检查。

视觉验收未完成：通过 Computer Use 读取微信开发者工具实际状态，但打开创建预约表单的自动化操作没有生效；未获取新版表单截图，因此不标记图像比对通过。仍需在开发工具或真机核对双列长标题、选中状态、横向日期滚动与底栏遮挡。没有创建真实预约或修改服务端数据。
