# 地址与服务形式：模拟器视觉验收

日期：2026-10-30。范围为地址管理、地址编辑、普通预约、报价单预约、服务形式、店铺管理六页。

- `narrow/`：iPhone 5，320 × 568 逻辑像素。
- `wide/`：iPhone 15 Pro Max，430 × 932 逻辑像素，包含底部安全区。
- 每组包含 13 张原生模拟器截图，以及输入框、单按钮/双按钮底栏的实际边界测量 JSON。
- 使用本地模拟请求及虚构姓名、地址、电话；没有保存地址、店铺或提交预约，没有向生产接口写入测试数据。结束后恢复账号与请求接口，并恢复原模拟器机型。
- 长姓名、长地址、状态卡片与底部布局截图已人工查看；输入框和双按钮底栏实际高度均不低于 44px，双按钮没有越出视口。
- `address-edit-keyboard-simulated.png` 通过模拟键盘高度事件验证底栏隐藏，不代表真机软键盘测试。
- 真机软键盘、腾讯地图授权、地图返回和路线导航仍需真机验收。收费档位增删与地图取消/权限分支由既有自动化行为测试覆盖，不将其等同于本轮截图验收。

本轮视觉验收发现并修复：地址页未注册路由；自定义按钮宿主布局导致底栏越界；窄屏 rpx 控件不足 44px；预约地址编辑按钮长文案折行；报价预约独立底栏重复实现；错误态按钮沿用旧样式。
