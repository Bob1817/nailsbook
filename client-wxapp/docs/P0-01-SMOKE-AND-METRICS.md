# P0-01 核心流程冒烟与指标口径

## 1. 核心冒烟清单

每次发布候选版本至少执行以下流程。`P0 当前` 表示现有能力应保持可用，`后续 P0` 表示相应模块开发后加入发布门禁。

### 身份与权限（P0 当前）

- [ ] 客户手机号或微信登录成功；
- [ ] 美甲师手机号或微信登录成功；
- [ ] Access Token 失效后只刷新一次并重放请求；
- [ ] 未认证用户不能调用经营端写接口；
- [ ] 美甲师不能读取或修改其他美甲师的数据；
- [ ] 公开接口不需要登录且不返回敏感字段。

### 公开主页与作品（P0 当前/后续 P0）

- [ ] 未登录访客通过美甲师 ID 或分享入口打开主页；
- [ ] 只显示 active 美甲师和 approved/public/visible 作品；
- [ ] 下架作品不能通过普通公开详情访问；
- [ ] 公开页面不显示精确地址、客户身份或内部备注；
- [ ] 来源参数在主页、作品、咨询和预约间保留；
- [ ] 弱网加载、空状态、失败重试可用；
- [ ] 微信分享标题、描述和封面正确。

### 咨询与线索（后续 P0）

- [ ] 主页咨询表单可在未登录状态提交；
- [ ] 作品入口自动带入意向作品；
- [ ] 相同提交不会生成重复线索；
- [ ] 美甲师可在 30 秒内手工新增微信咨询；
- [ ] 暂缓线索可以恢复；
- [ ] 未成交必须记录原因；
- [ ] 转客户和预约时不重复输入已有信息；
- [ ] 首次渠道来源在转换后保留。

### 预约（P0 当前/后续 P0）

- [ ] 客户提交的是待确认申请，不直接成为已确认预约；
- [ ] 美甲师可以确认、调整或拒绝；
- [ ] 同一美甲师重叠时段产生明确冲突；
- [ ] 重复提交不会创建重复预约；
- [ ] 非法状态跳转由服务端拒绝；
- [ ] 取消和爽约必须记录原因；
- [ ] 取消、拒绝和爽约不计入完成收入。

### 完成服务与服务后任务（后续 P0）

- [ ] 完成服务记录实际金额、耗时和成本；
- [ ] 重复完成不会重复入账；
- [ ] 完成后生成护理、评价、授权、作品和复购任务；
- [ ] 同一业务任务不会重复生成；
- [ ] 未授权照片不能发布；
- [ ] 撤销授权后公开内容立即停止展示；
- [ ] 从订单创建作品不重复输入客户和服务信息；
- [ ] 只有已完成订单可以提交已验证评价。

### 客户与经营数据（P0 当前/后续 P1）

- [ ] 客户详情展示正确的订单和消费数据；
- [ ] 首次来源不会被后续复购覆盖；
- [ ] 过敏/禁忌在预约和服务环节突出；
- [ ] 经营汇总可以下钻到明细；
- [ ] 相同筛选条件下汇总与明细一致；
- [ ] 跨月、空数据和部分数据均正常；
- [ ] 数据导出只包含当前美甲师数据。

## 2. 统一指标口径

除特别说明，业务时区统一使用 `Asia/Shanghai`，收入按服务完成时间归属日期。比率分母为 0 时返回空值而不是 0%，避免错误表达。

### 咨询

| 指标 | 统一定义 | 去重/排除规则 |
|---|---|---|
| 新增咨询数 | 统计期内创建的 Lead 数量 | 排除测试、垃圾、系统重复记录 |
| 有效咨询数 | 联系方式有效，且需求、预算、期望时间或意向作品至少有一项有效信息的 Lead | 同一美甲师、同一联系方式、同一需求窗口内合并重复记录 |
| 待回复咨询 | 状态为 new，或最后一条客户消息后没有美甲师响应 | 排除 lost、converted |
| 逾期跟进 | 下次跟进时间早于当前时间且任务仍为 pending | 同一线索同一目的只保留一个有效任务 |

### 预约

| 指标 | 统一定义 | 去重/排除规则 |
|---|---|---|
| 预约申请数 | 统计期内提交并成功创建的待确认预约 | 幂等键相同只计一次 |
| 已确认预约数 | 统计期内首次进入 confirmed/待服务状态的预约 | 取消后重新确认仍按同一预约计一次 |
| 咨询转预约率 | 来源于有效咨询的预约申请去重数 ÷ 有效咨询数 | 使用 Lead → Appointment 关系，不按按钮点击推断 |
| 预约确认率 | 已确认预约数 ÷ 预约申请数 | 拒绝和客户取消保留在分母 |
| 到约率 | 进入服务中、已完成或明确到场状态的预约数 ÷ 已确认且已到预约时间的预约数 | 美甲师取消不进入分母；客户取消和爽约进入分母 |
| 完成订单数 | `completedAt` 落在统计期内的去重预约数 | 排除取消、拒绝、爽约、过期 |

### 客户

| 指标 | 统一定义 |
|---|---|
| 潜在客户 | 有有效咨询但没有完成服务的去重客户 |
| 新客 | 在统计期内完成其在该美甲师处第一笔服务的客户 |
| 老客订单 | 客户第一笔完成服务之后的完成订单 |
| 活跃客户 | 最近服务日未超过其建议维护日期的客户 |
| 待复购客户 | 已超过建议维护日期且没有后续有效预约的客户 |
| 沉睡客户 | 超过配置沉睡天数且没有后续有效预约的客户 |
| 月度有效经营客户数 | 当月完成服务，且产生公开/内部评价、复购预约或有效转介绍至少一种行为的去重客户数 |

客户去重优先使用同一美甲师下的正式 Customer ID；合并客户后统一归属于保留记录。不能用昵称去重。

### 收入

| 指标 | 统一定义 |
|---|---|
| 完成收入 | `completedAt` 在统计期内的完成订单实收金额总和 |
| 客单价 | 完成收入 ÷ 完成订单数 |
| 材料成本 | 完成订单关联 ServiceRecord 的材料成本总和 |
| 毛利 | 完成收入 − 材料成本；MVP 不包含人工、房租、平台费和税费 |
| 预计收入 | 已确认但未完成、未取消、未爽约预约的确认价格总和 |

金额必须使用最小货币单位或可靠 Decimal；取消、拒绝、爽约和过期订单不进入完成收入。

### 复购

| 指标 | 统一定义 |
|---|---|
| 复购客户 | 在该美甲师处至少完成两次服务的客户 |
| 30/60/90 天复购率 | 首次完成服务后对应天数内再次完成服务的客户数 ÷ 已拥有完整观察窗口的首购客户数 |
| 平均复购间隔 | 同一客户相邻完成服务日期间隔的平均值 |
| 复购预约 | 客户已有历史完成服务，且创建了新的有效预约 |
| 复购联系率 | 已处理的复购联系任务数 ÷ 到期复购联系任务数 |

未拥有完整观察窗口的客户不进入对应 30/60/90 天复购率分母。取消的后续预约不算复购完成，但可以单独统计复购意向。

## 3. 发布门禁

每一批完成时必须报告：

1. 解决的用户问题；
2. 修改的页面、接口、模型和规则；
3. 数据迁移与兼容影响；
4. 执行的自动化检查及结果；
5. 对应冒烟场景结果；
6. 尚未覆盖的风险；
7. 回滚方法；
8. 下一批建议。

任何涉及数据库结构的批次，在全新数据库 schema diff 不为零或历史副本迁移未验证时，不得宣称生产迁移已完成。
