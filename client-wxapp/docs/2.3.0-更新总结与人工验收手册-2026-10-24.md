## 2. 本次更新的业务原则

系统收口为三个核心对象：

1. **客户**：保存跨多次服务都需要复用的个人信息，如过敏、禁忌、喜好和稳定偏好。
2. **预约**：承载本次服务的时间、地点、报价、服务项目、客户和来源作品。
3. **作品**：保存同款或同类服务可复用的制作信息，如工具、材料、前置准备、关键步骤和历史耗时。

**美甲服务**仍指美甲师提供的项目及定价。  
**美甲记录**是一次预约完成后的服务总结，用于连接客户、预约和作品，两者不是同一类数据。

## 3. 更新内容详细总结

### 3.1 客户端预约入口收口

- 作品详情和公开作品页保留“预约同款”，作品作为预约来源传入。
- 客户的“设计需求”、“定制款式”等原有分散入口统一转向预约流程，减少独立业务单据。
- 从作品发起的预约保留 `sourceWorkId`，便于美甲师在预约中识别客户想做的款式。
- 对价格和服务项目已确定的作品，可生成待客户确认的预约；信息不足时进入待报价。

### 3.2 美甲师快速报价

- 美甲师首页增加快速报价入口。
- 报价支持选择已绑定客户、服务项目、数量、日期、时间和地点。
- 支持核心服务、附加项和最终价格的组合。
- 极简预约可使用手工报价；已有结构化服务的预约需使用服务明细，防止数据退化为一段文字。
- 报价带有版本号。客户确认旧报价时，应被提示刷新，避免确认已被美甲师修改的方案。
- 客户可查看报价明细后确认或要求调整；美甲师修改后可重新提交。

### 3.3 预约详情中的服务前信息

美甲师查看预约时，页面将组合显示两类信息：

- **客户维度**：过敏、禁忌、偏好、最近服务结论等。
- **作品维度**：工具、材料、前置准备、关键步骤、风险注意事项和历史耗时。

客户信息不同步到公开作品。作品制作方案也不改变客户个人档案。

### 3.4 美甲记录与预约完成

“完成服务”页已调整为“美甲记录”，并按服务阶段组织：

1. **服务前**
   - 查看客户已有的过敏和禁忌。
   - 确认已知悉客户安全信息。
   - 上传服务前照片。
   - 使用可选标签或文字记录甲面、甲型、受损和敏感情况。
   - 记录本次注意事项和客户临时需求。
2. **过程细节**
   - 默认收起，需要时展开，避免增加日常操作负担。
   - 可上传过程照片，记录本次实际使用的材料、工具、步骤与技法。
   - 可记录客户过程反应和不适或异常。
3. **完成后**
   - 记录开始/结束时间、实收金额和材料成本。
   - 上传完成后照片。
   - 选择客户反应，补充客户反馈、本次偏好观察、护理建议和下次服务准备。
4. **沉淀作品经验**
   - 可选择将工具、材料、制作步骤和耗时同步到关联作品。
   - 过敏、禁忌、客户反应等个人信息仅保留在客户和美甲记录中。

页面会自动保存已填写内容，并显示“保存中”、“已保存”或“保存失败·重试”。缺少服务前照片、完成后照片、甲面情况或客户反应时，预约仍可完成，但美甲记录应标记为“待补全”，而不是丢失本次服务。

### 3.5 客户详情页精简

- 移除与美甲记录重复的“客户跟进记录”卡片。
- 不再把“关联作品”作为一块独立历史卡片展示。
- 美甲记录移到客户详情页底部，列表只显示日期、服务摘要、照片数和完善状态等基本信息。
- 点击某次记录后，再在记录详情页查看照片、美甲总结、关联预约和关联作品。
- 美甲记录与客户档案各自承担明确职责：本次差异留在记录，跨次服务仍有效的信息才沉淀为客户信息。

### 3.6 作品制作方案与来源回查

- 完成服务时可把实际使用的工具、材料、制作步骤、注意事项和耗时同步为作品准备信息。
- 空值不应覆盖作品已有的准备信息。
- 作品详情显示制作准备及其来源服务，可回查对应的美甲记录和预约。
- 同一条美甲记录重复同步时，不应重复增加来源次数。

### 3.7 行程、预约列表和首页操作

- 预约卡片操作根据当前状态出现，减少在多个页面重复判断。
- 待报价、待客户确认、待美甲师确认、服务中和已完成的卡片应显示不同主操作。
- 首页增加与当前主流程相符的快捷入口，并保持手机端主要操作可触达。

### 3.8 消息图片回归验证

本版发布前门禁覆盖了对话列表、图片发送队列和恢复逻辑。人工验收仍需在双账号下确认：

- 发送方头像和气泡在右侧，接收方在左侧，头像与内容顶部对齐。
- 图片发送成功后双方都能看到同一条消息。
- 点击图片可查看大图并在多张图片之间预览。
- 弱网失败任务可重试，恢复页面后不重复发送已成功消息。

## 6. P1 稳定性和边界验收

### P1-01 弱网下的美甲记录

- [ ] 在弱网或断网下修改字段，页面出现明确失败状态。
- [ ] 恢复网络后点击“重试”，保存成功。
- [ ] 退出重进后内容存在，不出现空白记录或重复记录。

### P1-02 弱网下的消息图片

- [ ] 开始上传图片后断网，确认失败任务有明确提示。
- [ ] 恢复网络后重试，只生成 1 条成功图片消息。
- [ ] 退出对话页后重新进入，失败队列可恢复，已成功消息不重发。

### P1-03 空值不覆盖作品经验

- [ ] 先让 W1 存在完整工具、材料和步骤。
- [ ] 新建一次关联 W1 的服务，本次不填某个制作字段，但选择沉淀作品经验。
- [ ] 保存后确认 W1 的原有字段没有被空值清除。

### P1-04 数据隔离

- [ ] 使用另一名美甲师 C 登录，确认无法读取 A 的客户档案、美甲记录和作品制作私有信息。
- [ ] 使用另一名客户 C2 登录，确认无法访问 B 的预约和消息。

### P1-05 手机端布局

- [ ] iPhone 和 Android 上固定底部操作区不遮挡内容或系统安全区。
- [ ] 键盘弹出后，当前输入项和主操作仍可触达。
- [ ] 主要按钮和选项可用单手点击，不依赖悬停状态。
- [ ] 长标题、长客户备注和多服务项目不溢出或遮挡金额。
