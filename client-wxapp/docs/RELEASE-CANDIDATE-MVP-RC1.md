# luanails MVP RC1 发布候选说明

候选版本：`luanails-mvp-rc.1`
整理日期：2026-07-30
状态：自动化验证和微信开发者工具编译通过，待冻结提交及双账号、真机验收

## 1. 候选目标

该候选版本用于形成 luanails 新定位下的第一版可验收基线，覆盖：

- 现有客户端和美甲师端核心预约闭环。
- 客户作品授权、美甲档案、评价和照片。
- 私人设计、作品分享和美照工作台。
- 美甲师客户、服务、排班、门店和标签管理。
- 统一经营概览、平均客单价和复购率。
- 预约时间冲突、单实例档期并发和状态操作幂等保护。
- 最新产品需求、技术方案和 MVP 优先级任务清单。

推荐关系和美甲基金尚未进入该候选版本。

## 2. 候选范围

### 包含

- `backend/`：NestJS 服务、Prisma schema、26 个数据库迁移和测试。
- `client-wxapp/`：微信小程序 59 个已注册页面、组件、服务和工具。
- `client-wxapp/docs/`：产品、技术、MVP 计划、冒烟和发布文档。

### 明确排除

- `mobile-flutter/ios/Runner/Base.lproj/Main.storyboard`
- `admin-frontend/`
- `client-frontend/`
- `technician-frontend/`
- `landing-frontend/`
- `website/`

上述项目不属于本次微信小程序 MVP 候选范围。本候选冻结时不得将其未关联改动混入提交。

## 3. 主要变化

### 产品定位

- 产品由预约和作品工具调整为自由美甲师个人商业经营系统。
- 保留作品、美甲档案和分享能力，将其用于客户资产及个人品牌经营。
- 后续 MVP 主线明确为客户 CRM、单层推荐、美甲基金和经营分析。

### 客户端

- 首页、发现、作品、美甲档案、预约、消息和个人中心体验完善。
- 新增美甲档案和美照工作台。
- 完善私人设计创建、报价、接受、拒绝、删除和转预约。
- 完善地址、收藏、点赞、评论及分享回跳。

### 美甲师端

- 完善订单、客户、作品、私人设计需求和服务管理。
- 增加客户关联作品和标签模板。
- 完善服务时间、休息日、上门设置及门店管理。
- 经营概览改用服务端统一指标，并展示收入、客单价和复购率。

### 后端

- 增加作品与客户、订单和独立权限关联。
- 增加分享令牌、分享事件、评价、客户照片及客户记录备注。
- 增加私人设计完整业务接口。
- 增加美甲师经营概览接口。
- 修改预约时间时同步检查和维护占用时段。
- 单实例 SQLite 下按美甲师串行执行档期写入。
- 完成、取消使用条件更新抢占状态流转权，收入由订单唯一约束防重。

## 7. 数据库部署

完整步骤以 [DATABASE-MIGRATION-DEPLOYMENT.md](../../backend/docs/DATABASE-MIGRATION-DEPLOYMENT.md) 为准。

核心要求：

- 部署前停止写入并用 SQLite `.backup` 创建完整备份。
- 历史 `db push` 数据库必须先执行结构预检。
- 只有预检完整通过后才能标记历史对账迁移。
- 执行 `prisma migrate deploy`，禁止在生产使用 `migrate reset`。
- 部署后执行迁移状态、schema diff、外键和完整性检查。

## 8. 应用部署顺序

1. 停止外部写入。
2. 备份并校验生产数据库。
3. 部署数据库迁移。
4. 启动新后端并执行只读健康检查。
5. 验证登录、公开作品和经营概览。
6. 发布微信小程序候选体验版。
7. 完成双账号核心冒烟。
8. 恢复外部流量。

## 9. 回滚方案

### 应用回滚

- 保留上一版本后端构建和配置。
- 新版本启动或冒烟失败时停止新后端，恢复上一版本。
- 小程序正式发布前先使用体验版验证；正式版本异常时按微信平台能力回退。

### 数据库恢复

- SQLite 迁移不执行逆向 SQL。
- 停止失败版本写入。
- 保留失败数据库用于排查。
- 将连接切换到升级前完整备份。
- 执行 `PRAGMA integrity_check` 和核心数据数量核对。
- 用上一版本后端完成只读冒烟后恢复流量。
