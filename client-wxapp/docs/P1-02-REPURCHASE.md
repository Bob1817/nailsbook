# P1-02 复购管理

- 正式服务支持维护周期（默认 21 天，最低 7 天）；完成服务时按服务周期计算建议复购日期。
- 行动中心对到期客户生成 `repurchase_contact` 任务，超过建议日期 28 天标记为沉睡联系。
- 唯一键包含客户和最近服务时间，同一次服务不会重复提醒；完成新服务后可形成下一周期任务。
- 已联系对应完成任务，稍后提醒对应 snoozed，无需联系对应忽略。
- 可从历史服务记录复制客户、服务、实际价格和服务方式创建新预约。
- 复购订单写入 `isRepeatBooking=true`、来源服务记录和 `existing_customer_repurchase` 归因；客户首次来源字段不修改。
