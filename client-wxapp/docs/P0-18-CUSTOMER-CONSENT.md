# P0-18 客户授权与删除规则

- 公开作品照片和公开评价分别使用 `work_photo`、`review_publication` 授权；有效授权必须包含授权主体、内容、展示身份、获取方式和授权时间。
- 旧评价的照片授权迁移为 `legacy_migration`，默认匿名展示；旧字段只作为兼容镜像，公开查询以有效统一授权记录为准。
- 单项撤权后，评价立即停止公开；作品立即转为内部状态并停止展示。
- 客户申请删除账号前调用全量撤权；系统在同一事务中撤销全部有效授权并停止关联内容公开。
- 删除客户或评价时保留授权审计记录，关联客户、评价外键置空；授权记录不包含联系方式。作品和评价内容是否物理删除由业务数据保留策略另行执行，但不得恢复公开。
