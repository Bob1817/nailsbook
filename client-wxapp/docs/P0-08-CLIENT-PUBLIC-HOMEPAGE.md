# P0-08 客户端公开主页

## 访客路径

- 公开主页首屏展示品牌定位、城市、公开服务区域、服务方式和可预约状态。
- 首屏后紧接真实评分、已完成评价数和公开案例数，不使用虚构信任数据。
- 精选作品和服务价格位于主页前两个内容分区，访客在首页一次滚动内即可看到价格。
- 页面底部固定“先咨询”和“立即预约”，任何滚动位置均可一次点击发起转化。

## 公开内容

- 品牌定位、美甲师介绍和审美理念。
- 精选作品、全部作品分页和作品结构化详情。
- 服务与价格摘要、全部服务分页和服务预选。
- 服务环境、卫生与材料保障、售后和取消规则。
- 已完成订单的真实匿名评价与 FAQ。

## 来源参数

- `source`、`campaign`、`content` 从公开主页传递到服务列表、作品列表、作品详情、咨询、预约和登录回跳。
- 微信分享卡片将 `source` 改为 `share_card`，并保留活动和内容标识。
- 预约页支持从服务页预选正式服务 ID。

## 状态与性能

- 主页、服务列表和作品列表具备骨架、空状态、错误文案和重试操作。
- 作品、环境图片和作品详情轮播均使用图片懒加载。
- 列表使用 P0-06 API 分页，页面不读取精确门店地址、内部联系方式或内部排期。
- 页面内容和固定 CTA 均预留 `safe-area-inset-bottom`。

## 三次点击验收

1. 访客打开品牌主页后直接看到服务价格，无需点击。
2. 点击价格行可预选服务并进入预约链路。
3. 任何位置点击底部咨询或预约，未登录访客经一次登录后回到原主页，整个意向发起路径不超过三次点击。
