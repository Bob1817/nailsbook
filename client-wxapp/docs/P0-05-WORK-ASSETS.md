# P0-05 作品案例资产升级

## 状态与公开规则

- `assetStatus` 统一为 `draft` 草稿、`internal` 内部、`public` 公开、`archived` 归档。
- `publicationStatus` 继续承担平台审核流程，与资产状态分开。
- 公开作品必须同时满足：`assetStatus=public`、`publicAuthorizationStatus=authorized`、`publicationStatus=approved`、`isVisible=true`、未归档。
- 提交发布前会再次检查公开授权；未授权作品不能进入审核流程。
- 归档为软归档，保留图片、服务、客户、预约和转化记录。

## 结构化字段

- 款式：风格、颜色、甲型、长度、适用肤色、适用场景、标签。
- 工艺：制作时长、工艺亮点、是否可复刻、复刻说明。
- 价格：不展示、固定价、起价、价格区间四种展示策略；新参考价以整数分存储。
- 经营：正式服务关联、客户授权关联、预约关联、精选、公开排序。

## 功能

- 经营端支持按标签、颜色、甲型和资产状态筛选。
- 复制作品会生成未授权草稿，不复制客户授权、互动、审核和发布状态。
- 旧删除接口保留兼容，但行为改为归档。
- 公开详情使用显式 DTO 白名单，不返回客户关联、预约关联、审核人、审核备注和授权内部状态。
