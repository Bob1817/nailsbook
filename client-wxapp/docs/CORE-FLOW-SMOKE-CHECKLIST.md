# NailArt Studio 核心流程冒烟清单

适用阶段：F1/F2。建议分别使用一个美甲师账号、一个已绑定客户账号和一个未绑定客户账号执行。

## 1. 作品预览与预约同款

- [ ] 已绑定客户打开公开作品，图片轮播、放大预览、标题和美甲师信息正常。
- [ ] 点击“预约同款”，创建预约页自动选中作品所属美甲师，并带入标题、描述和参考图。
- [ ] 完成时间、服务方式和地址选择后提交，订单进入 `pending_quote`，订单详情能看到来源作品。
- [ ] 已绑定客户打开自己的专属授权作品，可按相同步骤预约。
- [ ] 撤销专属作品查看权后再次提交同款预约，服务端提示来源作品授权已失效。
- [ ] 切换到其他美甲师或标准服务后，原来源作品关联被清除，不产生错误关联。

## 2. 公开分享入口

- [ ] 未登录用户从公开作品点击“预约同款”，完成登录后返回原作品的预约创建页。
- [ ] 新用户从同一入口注册并绑定作品所属美甲师后，返回原作品的预约创建页。
- [ ] 已登录且已绑定客户从公开作品直接进入预约创建页。
- [ ] 已登录但未绑定作品所属美甲师时，页面明确提示先完成绑定，不静默创建订单。

## 3. 预约状态机

- [ ] 客户提交预约后，美甲师收到预约消息并可报价。
- [ ] 客户接受或拒绝报价后，双方订单状态和对话系统消息同步。
- [ ] 美甲师确认排期后，上门/到店状态、地址和时间显示正确。
- [ ] 进行中订单可完成；非进行中订单不可越级完成。
- [ ] 可取消状态能够取消并释放时间段；不可取消状态被后端拒绝。
- [ ] 已完成订单可评价，其他状态不可评价。

## 4. 绑定与对话

- [ ] 邀请码注册或绑定申请不受作品权限功能影响。
- [ ] 美甲师审批后客户能查看其公开作品；解除绑定后不能再通过客户端私有接口访问。
- [ ] 客户和美甲师文字、图片消息正常发送、接收和刷新。
- [ ] 从对话“快速预约”进入时锁定当前美甲师。
- [ ] 预约卡片能从双方对话进入正确订单详情。

## 5. 分享、收藏与授权

- [ ] 公开作品可收藏、点赞、评论和微信分享。
- [ ] 专属作品只显示被授权的操作；未授权操作由后端拒绝。
- [ ] 专属作品分享链接在授权有效期内可打开，撤销或过期后立即失效。
- [ ] 分享动作和分享链接打开后，美甲师作品详情的传播次数增加。
- [ ] 客户评价照片默认不授权；开启、关闭授权后重新进入订单详情，状态保持一致。

## 6. 设备与权限

- [ ] iOS 与 Android 各完成一次图片选择、上传、保存相册和微信分享。
- [ ] 拒绝相册或相机权限时有可恢复提示，页面不白屏。
- [ ] 底部固定操作区不被系统安全区遮挡，所有主要触控区域不小于 44px。
- [ ] 弱网、接口超时和重复点击提交时不产生重复订单。

## 通过标准

所有 P0 项（第 1–4 节）必须通过；第 5–6 节若发现设备或微信环境问题，应记录设备型号、系统版本、基础库版本、复现步骤和截图后再发布。
