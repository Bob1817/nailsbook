# 小程序 2.3.0 发布前审计（2026-10-23）

> 候选版本号：`2.3.0`。这是发布建议，尚未上传微信、提交审核或发布。

## 一、候选版本范围

本次版本围绕“客户、预约、作品”三个核心对象收口，美甲记录作为服务完成后的总结，将一次预约、对应客户和产出作品关联起来。

1. 预约前：在预约详情查看客户稳定档案、最近服务结论，以及关联作品的工具、材料、步骤和预计时长。
2. 服务中：按服务前、过程中、完成后三个阶段保存照片，页面离开或网络失败后可恢复未完成内容。
3. 服务后：完善结构化美甲记录，可将作品图片和可复用的制作方案同步到作品；客户反应、禁忌、偏好等继续归属客户档案或本次记录。
4. 后续复用：客户详情以美甲记录为服务历史；作品详情可回查制作方案对应的来源服务和预约。
5. 入口精简：客户侧设计需求统一进入预约；客户详情移除重复的跟进记录与独立新建作品入口。

## 三、部署顺序

1. **冻结候选提交**
   - 只纳入本次确认的 `backend/`、`client-wxapp/` 及必要发布文件。
   - 推送候选提交，记录完整 commit SHA。
2. **CI 构建后端镜像**
   - 运行 `release-images.yml`，使用候选 SHA 构建 `ghcr.io/bob1817/nailsbook-backend:sha-<完整SHA>`。
   - CI 必须通过 schema drift、服务记录测试、后端构建和镜像构建。
3. **备份并部署 Backend**
   - 停止写入，使用 SQLite `.backup` 生成带时间戳的数据库备份，并确认 `integrity_check=ok`。
   - 将 `BACKEND_IMAGE` 固定为本次 SHA 镜像；ECS 只执行镜像拉取与容器更新。
   - 容器启动时自动执行 `prisma migrate deploy`；迁移失败时不得继续启动应用。
4. **生产 API 冒烟**
   - 确认健康接口、登录、预约详情、服务记录草稿、作品制作方案、客户档案读取正常。
   - 确认迁移状态无待执行项、schema 零差异、外键检查无异常。
5. **小程序体验版与提审**
   - 后端冒烟通过后，在微信开发者工具上传 `2.3.0`。
   - 设为体验版，完成下方双账号真机验收；全部通过后再提交审核。

## 四、真机必验核心闭环

### P0：阻断发布

- [ ] 客户从作品点击“预约同款”，提交预约后，美甲师在预约详情看到正确客户与作品。
- [ ] 美甲师报价，客户确认，双方预约状态一致。
- [ ] 美甲师开始服务，分别上传服务前、过程中、完成后照片；离开页面再进入，草稿与照片仍存在。
- [ ] 美甲师完成记录后，预约显示已完成，客户详情出现本次美甲记录。
- [ ] 将完成照片发布/关联为作品后，作品详情显示制作方案，并可回查来源服务与预约。
- [ ] 同一客户再次预约时，预约详情展示客户档案、最近服务结论和关联作品准备信息。
- [ ] 客户与美甲师双方发送文字和图片消息，图片可预览；失败任务可重试且不会重复发送。
- [ ] iOS 和 Android 各完成一次相册选择、拍照、上传和预览。

### P1：可记录后跟进

- [ ] 弱网下自动保存失败有明确提示，恢复网络后可继续保存。
- [ ] 重复点击完成、发布作品或同步制作方案不会生成重复记录或重复作品。
- [ ] 空的可复用字段不会覆盖作品已有制作方案。
- [ ] 客户禁忌、过敏和偏好不会被写入作品公共制作方案。
- [ ] 固定底部操作区不遮挡输入或系统安全区，主要控件触控高度不小于 44px。

## 五、回滚约束

- 部署失败时停止服务，保留失败数据库用于排查，恢复部署前完整 SQLite 备份和上一版本后端镜像。
- 两条服务记录迁移包含表重建与新增字段，不能用手工逆向 SQL 回滚；不得执行 `prisma migrate reset` 或用 `db push` 替代迁移。
- 小程序审核版本可撤回或回退代码，但必须确认回退客户端不会调用新接口；数据库中的新增表和字段可保留。

## 六、微信提审摘要

### 版本描述

本次版本优化美甲服务闭环：美甲师可在预约中查看客户历史与作品准备信息，服务过程中分阶段记录照片，服务完成后形成关联客户、预约与作品的美甲记录，并将可复用的工具、材料和制作步骤沉淀到作品中。同时精简重复入口和记录表单。

### 审核建议路径

1. 客户角色：浏览作品 → 预约同款 → 查看并确认报价 → 查看预约详情。
2. 美甲师角色：预约详情 → 查看服务前准备 → 开始服务 → 完善美甲记录 → 查看客户历史与关联作品。
3. 消息：客户与美甲师进入同一对话，发送文字和图片并预览。

### 审核备注

- 微信登录与手机号授权用于账号登录和预约联系。
- 相册/摄像头用于预约沟通、服务过程记录和作品图片上传。
- 消息图片为预约双方的一对一沟通内容；公开作品由入驻美甲师发布并受平台管理。
- 美甲记录中的客户禁忌、过敏、偏好和服务反应仅供对应美甲师服务准备使用，不作为公开作品信息展示。
- 提审前必须把“后端生产部署”状态更新为已完成，并记录镜像 SHA、数据库备份路径、部署时间和健康检查结果。
