# P0-07 美甲师主页配置

## 手机端配置范围

- 品牌资料：头像、名称、一句话定位、专业简介、城市、公开服务区域和审美理念。
- 服务与价格：从主页经营页进入 P0-04 正式服务管理。
- 环境与区域：公开区域、交通说明和最多 6 张环境照片。
- 专业保障：卫生消毒、材料标准和过敏提示。
- 服务规则：迟到、取消和售后补修规则。
- FAQ：支持手机端新增、编辑和删除。
- 分享与发布：分享标题、描述、封面、发布状态和客户视角预览。

## 保存与离开保护

- 品牌资料、环境与区域、专业保障、服务规则、FAQ、分享与发布六个分区可独立保存。
- 分区保存时使用最近一次已保存快照合并数据，不会提前写入其他未保存分区。
- 任一分区修改后启用小程序离开确认；全部保存后自动解除。
- 存在未保存内容时，从其他页面返回不会自动刷新并覆盖表单。
- 预览对应服务器已保存版本；有未保存内容时先引导保存。

## 发布校验

小程序和后端双重校验以下必填项：

- 品牌名称、头像、一句话定位、城市、公开服务区域和专业简介。
- 卫生保障、取消规则、环境照片。
- 分享标题和分享封面。
- 至少一项未归档且可预约的正式服务。

草稿可在信息不完整时分区保存，仅在切换到“公开发布”时执行完整校验。

## 图片上传

- 上传前使用微信 `compressImage` 按 82% 质量压缩，不支持时自动使用原图。
- 通过 `UploadTask.onProgressUpdate` 展示 0–100% 进度。
- 失败时保留当前表单，显示错误原因和重试入口。
- 服务端继续生成 high、medium 和 thumbnail WebP 图片变体。

## 移动端可用性

- 输入框、选择器、分区保存、重试、添加和页面主操作区均不小于 88rpx（44px）。
- 底部保存区保留 `safe-area-inset-bottom`。
- 保存中和已保存状态有文字反馈，不只依赖颜色。

## 验证

- `scripts/test-homepage-settings.js` 检查分区、离开保护、发布校验、压缩、进度、重试和 44px 触控尺寸。
- 后端测试覆盖完整主页发布以及缺失必填内容时拒绝发布。
