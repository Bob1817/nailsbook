# 内容与数据上线检查清单

## 上线前

- 为正式数据库创建可恢复备份，并记录备份时间与恢复负责人。
- 配置 `NODE_ENV=production`、`ADMIN_INITIAL_USERNAME` 和不少于 12 位的 `ADMIN_INITIAL_PASSWORD`。
- 确认生产环境未配置 `AUTO_SEED_DEMO_DATA=true`，且不存在 `source=demo_seed` 的订单。
- 执行 `npx prisma migrate deploy`，禁止在生产环境使用 `prisma db push`。
- 至少录入 1 位启用状态的真实美甲师，并完善头像、简介、邀请码、服务方式、项目价格和工作时间。
- 至少录入 6 个具有标题和图片的真实作品，由超管审核通过后再设置首页精选。
- 在超管后台完成微信登录和微信支付配置校验。

## 自动检查

在 `backend` 目录执行：

```bash
npm run check:production-readiness
```

可通过 `MIN_LAUNCH_TECHNICIANS` 和 `MIN_PUBLIC_WORKS` 调整首发内容数量门槛。命令返回非零状态时不得上线。

## 上线后抽查

- 游客发现页只显示审核通过、公开且所属美甲师处于启用状态的作品。
- 待审核或已驳回作品不能通过公开详情地址访问，也不能设为首页精选。
- 美甲师修改已发布作品后，作品重新进入待审核状态。
- 客户完成微信登录后可正常查看、点赞、收藏和关注作品或美甲师。
- 真实定金支付和尾款支付各完成一笔，后台到账金额与微信商户平台一致。
- 检查支付回调、订单入账和邀请基金流水不存在重复记录。

## 回滚原则

- 应用异常时先回滚应用版本，不直接删除正式数据。
- 数据迁移后出现问题时使用上线前备份恢复；不要手工修改支付单、订单实付金额或邀请基金流水。
- 内容问题优先在超管后台驳回或下架，不物理删除作品。
