# 美甲记录与私密档案闭环测试用例

日期：2026-10-26  
状态：待执行  
适用范围：微信小程序美甲师端、客户详情、作品详情、预约详情及后端档案接口

## 1. 测试目标

验证美甲师可以完整记录一次美甲过程，并在明确确认后把客户相关信息和作品制作经验分别同步到私密客户档案与作品档案。再次预约时，美甲师能够看到已确认的客户提醒及作品所需工具、材料和步骤，同时客户、其他美甲师和公开接口不能读取这些私密档案。

## 2. 测试边界

- 美甲记录是单次服务事实，允许自动保存和后续编辑。
- 客户档案、作品档案必须由美甲师手动同步。
- 自动保存不能触发档案同步。
- 已同步档案不会因原始记录再次编辑而自动覆盖。
- 私密档案仅对创建它的美甲师可见。
- 本轮不验证客户公开展示、跨美甲师共享或自动生成档案。

## 3. 测试环境与账号

| 编号 | 测试对象 | 要求 |
| --- | --- | --- |
| T1 | 美甲师 A | 拥有客户 C1、作品 W1 和可完成的预约 O1 |
| T2 | 美甲师 B | 与美甲师 A 无共享关系，用于验证越权隔离 |
| C1 | 客户账号 | 与美甲师 A 存在预约关系 |
| W1 | 关联作品 | 属于美甲师 A，初始制作方案版本为 V1 |
| O1 | 正常预约 | 绑定 C1 与 W1，状态可进入服务中和已完成 |
| O2 | 无作品预约 | 绑定 C1，不绑定作品 |
| O3 | 不可记录预约 | 状态为取消、拒绝、过期或未到店之一 |

测试前记录数据库中 C1 的档案条数、W1 的方案版本和修订数，便于验证是否发生非预期写入。

## 4. 通用记录样本

| 字段 | 样本值 |
| --- | --- |
| 甲面情况 | 甲面偏薄，右手食指边缘轻微分层 |
| 工具 | 短柄圆头笔、180 目砂条、点钻笔 |
| 材料 | 裸粉色胶 NP-07、加固胶 BG-02、银色钻饰 |
| 步骤与技法 | 薄涂加固两遍，食指边缘局部补强，最后点钻 |
| 过程异常 | 打磨食指时客户反馈轻微发热，降低转速后恢复 |
| 客户反馈 | 喜欢短甲和自然色，下次避免高亮钻饰 |
| 偏好观察 | 偏好短方甲和低饱和裸色 |
| 下次提醒 | 右手食指先检查分层情况，打磨使用低速 |
| 护理建议 | 24 小时内避免长时间泡水 |

## 9. 执行顺序和停止条件

正式测试按以下顺序执行：

1. 先运行不修改生产数据的静态契约和单元测试。
2. 再在本地或专用测试库执行记录、同步、失败重试和数据一致性测试。
3. 然后在微信开发者工具进行双端页面和交互验收。
4. 最后只对生产环境执行只读健康与权限边界检查。

出现以下任一情况时停止后续测试并记录现场：

- 客户档案或作品档案发生跨账号泄露。
- 自动保存触发档案同步。
- 同步失败导致原始美甲记录丢失。
- 作品当前方案与版本修订不一致。
- 生产测试需要创建、修改或删除真实业务数据。

## 10. 通过标准

- 所有 P0 用例通过。
- P1 用例无阻断核心流程的问题。
- 客户档案、作品档案和关联更正不存在越权或串档。
- 自动保存、手动同步和独立重试的边界符合设计。
- 作品版本与修订历史一致，客户重复确认不产生重复事实。
- 微信小程序页面在目标设备中不存在遮挡、溢出或不可点击控件。
