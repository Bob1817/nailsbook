# P0-21 评价闭环

- 评价真实性由已完成订单产生，`verificationSource=completed_order` 只能由服务端写入。
- 每个订单最多一条评价；提交后不可用重复提交覆盖原评价。
- 美甲师可为已完成且未评价的订单生成唯一邀请链接，令牌仅存 SHA-256 哈希，默认 7 天有效，使用后失效。
- 客户可以匿名或使用指定昵称，并单独授予或撤销公开授权。
- 新评价默认 `pending/private`；审核通过后为 `approved/public`，公开接口还必须同时找到未撤销授权。
- 美甲师可以回复评价；公开 DTO 只输出展示名、评价内容、经授权照片和回复，不输出客户 ID、联系方式、订单 ID或邀请令牌。
- 后台审核接口只能改变审核与公开状态，不能创建评价或修改已验证来源。
