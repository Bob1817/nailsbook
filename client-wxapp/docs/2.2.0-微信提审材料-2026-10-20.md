# 小程序 2.2.0 微信提审材料（2026-10-20）

> 直接复制以下各节到微信公众平台提审表单对应字段。

## 一、版本说明（提审表单「版本描述」）

本次版本新增「预约报价」能力：美甲师可针对客户预约发起快捷报价，客户在小程序内查看报价单并确认预约；同时修复预约沟通中图片消息的可靠性问题，优化美甲师首页与发现页体验。

## 二、功能说明（提审表单「功能描述」）

本小程序是美甲服务预约平台，客户浏览美甲师作品、预约服务；美甲师管理预约、客户与作品。

本版本主要功能点：

1. 预约报价闭环
   - 美甲师对客户预约发起快捷报价：选择/新增服务项目、按小时填写服务时长、调整最终报价（最终报价不高于项目合计）。
   - 报价单预览与分享：美甲师、店铺、报价信息分区展示；客户打开报价单确认预约。
2. 预约确认流程
   - 待确认预约支持「同意预约 / 驳回申请」，驳回需填写原因，操作结果实时通知客户（微信订阅消息）。
3. 预约沟通图片消息
   - 客户与美甲师在预约沟通中发送图片，支持预览、发送失败重试与撤回。
4. 体验优化
   - 美甲师首页快捷操作与空行程卡片布局优化；发现页对齐搜索栏、分类导航与两列瀑布流结构。

## 三、审核注意事项（提审表单「审核备注」）

1. 登录方式：微信一键登录（getPhoneNumber 手机号授权），无需测试账号。审核时可分别体验客户与美甲师两种角色。
2. 建议审核路径：
   - 客户角色：首页 → 发现页浏览作品 → 发起预约 → 查看报价单并确认。
   - 美甲师角色：首页 → 待确认预约 → 同意/驳回 → 快捷报价 → 生成报价单。
3. 涉及的微信能力及用途：
   - 手机号快速验证（getPhoneNumber）：用于账号注册与登录。
   - 订阅消息：用于预约状态变更、报价单通知，发送前均经用户授权。
   - 相册/摄像头（chooseMedia）：用于美甲师上传作品图、预约沟通中发送图片。
4. 图片消息为预约双方一对一沟通内容，非公开 UGC；作品展示内容均由平台入驻美甲师发布并经平台管理。
5. 用户隐私：小程序收集手机号用于登录与预约联系，隐私协议已在「我的 → 设置 → 隐私协议」中公示。
6. 后端服务已同步更新至对应版本，提审期间服务保持可用。
