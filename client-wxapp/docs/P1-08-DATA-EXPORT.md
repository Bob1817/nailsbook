# P1-08 数据导出

- 数据集：客户资料（`customers`）、预约/服务记录（`bookings_services`）、作品元数据（`works`）、经营明细（`business`）。
- 每类数据支持 CSV 和 JSON；JSON 包含 schema 版本与数据集标识，CSV 对公式注入字符和引号换行做转义。
- 所有查询强制使用登录美甲师 ID，不能通过参数指定其他美甲师。
- 默认客户导出不包含电话、地址、过敏和禁忌；敏感字段需先获取一次性确认令牌，5 分钟过期且使用后失效。
- 每次导出记录数据集、格式、行数、筛选条件、是否包含敏感字段和时间。
- 测试将 JSON 重新解析，并使用 CSV 解析规则检查列数和转义，确保文件可重新读取。
