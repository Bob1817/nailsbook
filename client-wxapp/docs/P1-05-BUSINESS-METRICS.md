# P1-05 经营指标服务

- 流量：主页访问统一计入 `homepage_view + artist_view`，作品访问使用 `work_view`。
- 有效咨询：筛选期内成功落库并完成短时去重的线索。
- 咨询转预约率：已转预约线索 / 有效咨询。
- 预约确认率：正式预约及已完成预约 / 预约申请；到约率：已完成服务 / 已确认预约。
- 新客订单是客户在数据集中的首次订单，其余为老客订单；订单同时保留明确复购标记。
- 30/60/90 天复购：首次服务后对应天数内再次完成服务的客户 / 有首次服务客户。
- 评价率：已提交评价订单 / 已完成订单；转介绍订单要求订单存在推荐关系归因。
- 收入取服务记录实收，毛利为实收减材料成本。
- 接口支持 `from`、`to`、`channel`；返回筛选条件和全部口径说明。
- 比例指标同时返回分子、分母和最低样本量；分母少于 20 时标记数据不足。
