# 首次使用引导方案

## 目标与触发范围

引导只服务于刚完成注册或首次完成身份选择的用户，帮助用户理解下一步如何使用产品。普通登录、角色切换和再次打开小程序不会主动触发引导。

- 客户入口：统一邀请码注册、兼容客户注册页、微信邀请注册、首次设置密码、首次选择客户身份。
- 美甲师入口：激活密钥注册、微信激活注册、首次设置密码、首次选择美甲师身份。
- 跳过和完成都会按角色记录 `first_use_onboarding_v2_<role>`，便于后续判断与版本升级。
- 引导页冷启动时保留当前页面，登录态恢复不会把未完成引导提前跳到首页。
- 客户完成后进入客户首页，并保留注册前的安全站内回跳；美甲师完成后进入工作台。

## 客户引导

1. **发现心仪款式**：查看作品、服务和美甲师主页，先形成明确偏好。
2. **完成一次预约**：选择服务、日期、时间和门店，补充需求后提交。
3. **随时管理行程**：通过订单与消息查看状态、沟通调整并完成评价。

## 美甲师引导

1. **完善接单资料**：补充个人、门店、服务和作品信息。
2. **设置可预约时间**：维护营业时间、休息时段并处理待确认预约。
3. **开始经营客户**：分享邀请码，在工作台管理预约、客户档案和服务记录。

## 交互与视觉规则

- 每页只说明一个任务，固定三步，显示当前进度。
- 支持跳过、上一步、下一步和完成；所有操作触控高度不低于 44px。
- 固定操作区适配底部安全区，短屏内容可滚动。
- 使用项目中性颜色令牌和现有图标，不使用装饰性高饱和颜色。
- 引导内容仅覆盖当前上线的微信小程序，出口接入小程序现有首页。

## 验收标准

- 两个角色均有且只有三步，内容与角色任务一致。
- 新注册入口全部进入正确角色的引导，普通登录不强制进入。
- 跳过/完成只能触发一次跳转，并写入带角色的完成记录。
- 客户注册前回跳在引导结束后才消费，美甲师进入工作台。
- 小程序发布门禁、后端单元测试与构建通过。
