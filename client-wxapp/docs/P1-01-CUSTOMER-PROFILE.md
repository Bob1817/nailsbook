# P1-01 客户档案升级

- 生命周期阶段：潜在、新客、活跃、待复购、沉睡；无服务记录默认为潜在，其余阶段按服务周期计算。
- 人工调整阶段必须填写原因，并写入独立历史记录；人工阶段优先于自动计算结果。
- 档案支持风格、颜色、甲型、长度、价格区间、过敏、禁忌、特别提醒和推荐人。
- 首次来源 `sourceType/sourceRef` 保持不覆盖；客户详情聚合咨询、预约、服务时间线、作品及评价。
- 最近服务、累计消费和服务次数由服务完成事务维护，并在详情中使用确认收入复核。
- 再次预约复用现有客户会话/预约入口。
- 合并只允许同一美甲师数据；迁移订单、收入、服务记录、线索、作品访问及授权后删除重复档案。绑定不同客户端账号时拒绝自动合并。
- 删除默认执行匿名化：清除身份、联系方式、地址和风险备注，归档档案，保留财务、服务和授权审计。
