# NailBook 颜色规范 v3

## 功能字段统一规则（2026-09-07）

下表是小程序功能字段的当前执行口径，覆盖下文旧状态去色条款；不改变其他端的中性色源。布局、字号、触控区域不随颜色治理改变。

| 功能 | 文字／图标 | 背景与例外 |
|---|---|---|
| 有效价格、收入、应付／已付金额 | money 深红 | 只强调金额；原价划线和“待报价”说明为 muted；深色选中底及图片遮罩上反白 |
| 查看、详情、更多、到店指引等文字导航 | textLink 深蓝 | 透明底；主按钮和整个可点击卡片不按链接染色 |
| 待报价、待确认、进行中 | textLink 深蓝 | softSurface 淡蓝灰；必须保留具体状态文字 |
| 待到店、营业、可接单、活跃 | success 深绿 | successSurface 浅绿；无真实数据不显示在线 |
| 已取消、已拒绝、已注销、已解绑、错误 | danger 深红 | 标签用 dangerSurface；错误文字不得沿用正文黑 |
| 已完成、已过期、休息、普通分类标签 | secondary 深灰 | page 浅灰；终态不冒充待办或成功提示 |
| 待复购 | customerDue 灰绿 | 保留专属客户语义，不套用订单状态 |
| 主按钮 | inverse 白 | action 石墨底，按压 actionPressed |
| 次按钮／关闭／返回／取消选择 | secondary 深灰 | softSurface；不是危险操作 |
| 删除、取消预约、确认拒绝 | danger 深红 | dangerSurface；保留二次确认 |
| 禁用按钮 | control 灰 | pressed 灰底；禁用优先于主操作／危险色，仍需真实 disabled 或业务拦截 |

点赞、收藏、作品置顶／推荐图标继续遵循下文专项例外。不得用全局 text/button 选择器或按字段名猜测的批量染色替代明确语义。小程序共享入口为 styles/tokens.wxss、styles/semantic-actions.wxss；隔离组件由生成器同步变量。

检查：sync-colors.py --check、check-colors.py、test-semantic-color-contract.js、test-booking-status-colors.js。静态检查不等于人工视觉验收。

生效：2026-08-27。本项目所有客户端、美甲师端、管理后台与官网共用。

## 权威与范围

本规范覆盖 AGENTS.md 引用的旧规范、UI-DESIGN-GUIDELINES、Flutter ET/DT 文档、历史 HTML 设计稿中的颜色条款。旧规范的移动优先、触控、安全区、字体和布局质量要求继续有效。不得修改其他项目的规范来影响本项目。

唯一基础色源：`colors.json`。运行 `python3 scripts/sync-colors.py` 同步平台文件；`--check` 检查漂移。生成文件不得手改。平台原有语义接口保留作为适配层，禁止新增 pink/orange 等色相命名接口。

## 基础与语义

| 名称 | 值 | 用途 |
|---|---|---|
| page | #F5F5F7 | 页面、轻分组 |
| surface | #FFFFFF | 卡片、表单、弹层 |
| pressed | #ECECEF | 次按钮按压底 |
| ink | #1D1D1F | 正文、金额、主操作 |
| secondary | #48484D | 次按钮及灰底说明 |
| muted | #6E6E73 | 白／page 底辅助文字与图标 |
| line | #E5E5EA | 装饰分隔线，不作唯一控件边界 |
| control | #8A8A8F | 控件边界、禁用文字 |
| link | #526477 | 少量链接、焦点、进行中提示 |
| activeSurface | #EEF1F5 | 进行中标签底 |
| action | #1D1D1F | 主按钮背景 |
| actionPressed | #343438 | 主按钮按压底 |
| inverse | #FFFFFF | 深底文字／图标 |

## 组件契约

- 主按钮：action/inverse；按压 actionPressed；禁用 pressed/control，保留 disabled 语义。主操作不再使用彩色渐变或彩色投影。
- 次按钮：surface/secondary，中性边界；按压 pressed。普通按钮不得默认使用低透明度文字。
- 卡片：surface；轻分组 page。按信息层级使用中性边界／阴影，不按业务模块分配色相。
- 图标：默认 muted、普通选中 ink、深底 inverse。业务语义状态优先于通用选中规则：小程序点赞使用 like（#B42332）实心爱心，收藏使用 favorite（#D4A017）实心黄色五角星，未选中均为灰色空心；黄色仅用于收藏图标，不用于小字号正文。通知、在线及导航选中状态继续使用各自语义色，不统一灰化。小程序继续使用受支持的 image SVG，不改为 CSS 本地 SVG 背景。
- 字段：surface/ink，必要边界 control；聚焦 link；错误有明确原因、字段关联与边界／图标提示。
- 状态：等待／完成／取消为中性标签，进行中允许 link/activeSurface；保留每一个业务状态与文案。禁止仅靠颜色区分。
- 小程序危险操作：删除、取消预约、拒绝等破坏性动作使用 danger 深红色，保留明确文案与确认；关闭弹窗／返回／取消选择不冒用危险红色。
- 图片遮罩：只保留中性透明黑／白渐变用于可读性。装饰用渐变改为实色；原生 Gradient 类型暂以同色 stops 兼容现有 API。
- 触控：实际高度至少 44 CSS px，移动优先并保留 safe-area。焦点不能只有 hover；保留按压反馈。

## 内容与平台例外

真实作品、头像、商品色卡、用户选择的甲色、照片滤镜及用户导出的海报画面配色不得去色；官方第三方标识及平台强制 UI 不擅自重绘。按具体文件／用途列入检查例外，不可用整目录忽略来掩盖残留。历史设计稿只供存档，不能作为新页面配色来源。用户保存的标签颜色不改数据库；普通 UI 标签展示使用中性语义。

## 验收

普通文字 ≥4.5:1，必要图形与控件边界 ≥3:1；灰底上的次文字用 secondary。禁用文字不拿来显示正常信息。图片／半透明组合须按最终画面检查。状态去色后，确认、错误、冲突、不可操作及危险动作仍可辨识。新页面必须使用语义变量；防回退检查同时检查 hex、rgba、Tailwind 预置色和原生色。

## 小程序语义强调（2026-08-28 用户修订，优先于旧“全中性”条款）

只作用于微信小程序；基础页面／卡片仍保持中性。唯一扩展色源为 miniprogram-semantics.json，由 sync-colors.py 输出 WXSS 与原生弹窗 JS 颜色。

| 语义 | 值 | 应用 |
|---|---|---|
| danger | #B42332 | 删除、取消预约、拒绝等危险操作；非整块业务卡片 |
| money | #B42332 | 价格、收入、已付／待付、余额、客单价等数字；订单数量／评分不使用 |
| textLink | #245EA8 | 更多、详情、查看等文字导航；不用于整个可点击卡片或底部导航 |
| secondary / muted | #48484D / #6E6E73 | 次要说明／辅助描述，保持正常文字可读性 |

文字链接默认透明背景、无装饰边框和阴影，保留原触控区域与按压反馈；不能为“去背景”缩小可点击范围。主提交按钮保留石墨底白字，不因为可点击就全部改为蓝色。危险按钮使用浅红底红字、无描边；禁用时回到禁用灰。金额只着重数字，不整段说明染色；照片叠加金额的白字／深遮罩作为可读性例外保留。彩色不得作为状态的唯一表达。三个新增语义色在白底及 page 底均需达到 4.5:1。


## 小程序无边框修订（2026-08-28，优先于上文旧边界条款）

仅迁移微信小程序，不继续修改 H5。参考 [Apple 官网](https://www.apple.com/iphone/) 的留白、分组与简洁层次，不照搬全黑白配色。

- 页面浅冷灰、卡片白色；次按钮和输入区域使用 softSurface（#EDF3FA）淡蓝灰，通过底色、间距、圆角区分层次。模块、按钮、列表分隔不使用实线描边，关闭微信 button::after 默认边框。
- 主操作保持石墨底白字；文字链接蓝字透明底；金额深红色；危险操作 dangerSurface（#FAECEE）浅红底红字。不可把整张业务卡片染成高饱和色。
- success（#287A4B）用于真实在线、营业／可接单及服务通知提示；successSurface（#EAF4EE）仅作轻背景。离线、休息、未知在线状态和普通系统通知使用灰色，保留文字说明。没有在线数据不能假装在线。
- CSS 绘制的箭头、图标、加载环、单选标记、状态点轮廓，以及真实作品／海报内容不属于模块边框，保留其可识别图形；焦点和选中态必须另有底色、勾选或按压反馈。
- 验收：生成色源一致、文字对比度通过、无模块实线边框回退、小程序 release gate 通过；开发者工具和真机视觉验收单独记录，不以静态检查替代。

### 小程序底部主菜单（2026-08-28 修订）

选中菜单使用 textLink 深蓝图标／文字、加粗图标线条和字重，并搭配 softSurface 淡蓝灰背景；未选中为 muted 灰色。选中背景与内容上下均保留 12rpx 内边距，保持触控高度与安全区。此规则覆盖此前底部导航只用中性色的规定。


### 客户卡片状态（2026-08-28）

活跃使用 success 绿字浅绿底；待复购使用 customerDue（#526B5B）灰绿；沉睡与尚无活跃记录的新客使用 muted 灰。状态点同步配色。明确 account.status=deleted 显示红色“已注销”，当前美甲师 bindingStatus=inactive 显示红色“已解绑”，两者优先于活跃度；未绑定不等于已解绑，匿名化不等于注销。终止关系隐藏预计复购时间，保留历史消费数据。三列指标等宽居中，金额保留红色。

### 作品状态图标（2026-08-30 用户修订）

作品左上角“已置顶”图钉使用 workPinned 浅蓝，“已推荐”星标使用 workFeatured 金色，来自 miniprogram-semantics.json。仅用于深色标签底上的状态图标，不用于正文或装饰背景；保留白色标签文字和现有深色底。此规则覆盖通用图标灰色及黄色仅限收藏图标的旧规则，颜色同步不得将这两个图标灰化。
