# 2026-08-07 CPU 高负载优化

## 根因分析
部署后服务器 CPU 持续 98%+，经代码审查定位到 3 个核心问题。

## 修复内容

### 1. orders.scheduler.ts — 头号 CPU 杀手
- **重复调用**：`handleOrderStatusTransitions()`（每 5 分钟）调用了 `sendDayBeforeReminders`，而该方法有独立 `@Cron('0 20 * * *')`。导致每天执行 289 次而非预期的 1 次。
- **修复**：移除 `handleOrderStatusTransitions` 中对 `sendDayBeforeReminders` 的调用
- **无分页 findMany**：5 个 findMany 均无 `take` 限制，全表扫描 + 顺序 for...of 嵌套事务处理
- **修复**：全部 5 个 findMany 加上 `take: 100` + `orderBy: { id: 'asc' }`

### 2. typing.service.ts — 定时器泄漏
- 5s 硬超时 `setTimeout` 从未被清除，用户多次发送 typing:start 后定时器累积，每次触发 WebSocket 广播
- **修复**：将 debounce 和 hardTimeout 两个定时器引用都存储，`stopTyping` 时全部清除；`startTyping` 时先清除旧定时器再创建新的

### 3. avatar-url.interceptor.ts — 响应遍历优化
- 全局拦截器递归遍历每个 API 响应，即使无 avatarUrl 也创建新对象（深拷贝）
- **修复**：用 `changed` 标记只在确实转换了 avatarUrl 时才返回新对象，否则返回原引用（零分配）

### 4. ThrottlerGuard 内存 Map 膨胀
- NestJS 默认限流器用内存 Map，高 QPS 下 TTL 过期记录不释放
- **修复**：新建 `throttler-cleanup.service.ts`，每 5 分钟 Cron 清理过期记录
- 注入 `@Optional()` 避免测试环境崩溃

# 2026-08-07 认证流程重构：恢复密码登录 + 微信注册设置密码

## 需求
- 恢复密码登录为正常登录方式
- 微信授权注册时，选手机号后必须设置密码
- 设置后，后续微信授权直接登录，密码登录用自设的密码
- SMS 仅用于忘记密码且无法微信登录时重置密码

## 修改文件

### 后端
1. **wechat-auth.service.ts `completeClient()`**：
   - 新用户免邀请码直接创建（`prisma.clientUser.create` 而非 `registerByInvite`）
   - 检查 `passwordHash`：为空 → 返回 `needsSetupPassword: true` + `passwordSetupToken`（调用 `clientAuth.createPasswordSetupToken()`）
   - 已有密码 → 正常微信登录

2. **client-auth.service.ts**：
   - 新增 `createPasswordSetupToken(clientId)`：签发 10 分钟有效的 JWT
   - 新增 `setupPassword(dto)`：验证 JWT → hash 密码 → 保存 → 清理 `managedPasswordCiphertext` → `loginByWechat`
   - `login()`：移除 SMS 注册用户拦截，`passwordHash` 为空统一返回"账号未设置密码，请通过微信登录设置密码"

3. **dto/setup-password.dto.ts**：`{ passwordSetupToken, password }`，密码用 `@IsStrongPassword()`

4. **client-auth.controller.ts**：新增 `POST /api/client/auth/setup-password`

### 小程序端
5. **services/api.js**：新增 `auth.setupPassword(token, password)`
6. **pages/login/index.js**：`onWechatPhone` 回调检查 `res.needsSetupPassword` → `wx.redirectTo` 设置密码页
7. **pages/setup-password/**（新建）：密码 + 确认密码 → 调用 API → 自动登录
8. **app.json**：注册 `pages/setup-password/index`

## 测试
238 tests 全部通过（含 4 个新/修改的 wechat-auth 测试）
