### 第十轮：小程序登录 401 + timeout 错误修复（今晚 22:30）
- **Bug 1 (timeout)**：`pages/login/index.js` 调用 `api.auth.wechatSession(code)`，但 `services/api.js` 未定义该方法 → TypeError 导致微信运行时 `SystemError timeout`
  - 修复：在 `api.js` auth 对象新增 `wechatSession: (code) => api.post('/api/wechat/auth/login', { code }, ...)` 
  - 后端 `WechatLoginDto.role` 为 `@IsOptional()`，不传 role 可正常返回 `wechatSessionToken`
- **Bug 2 (401 根因分析)**：`POST /api/client/auth/login` 的 401 来自 `client-auth.service.ts` login() 的 4 种 UnauthorizedException：
  1. 手机号不存在
  2. 账号被禁用 (status ≠ active)
  3. 未设置密码 (passwordHash 为空)
  4. 密码不匹配（SMS/微信注册用户有随机托管密码，用户输入永远不匹配）
- **Bug 2 修复**：`client-auth.service.ts` login() 在密码不匹配时检查 `managedPasswordCiphertext`，若 SMS 注册用户则返回明确提示"该账号通过短信验证码注册，请使用短信验证码登录"（而非通用"手机号或密码错误"）
- **⚠️ backend 有改动，需 commit 后推送阿里云部署**
