# 2026-08-08 统一登录/注册流程重构 + 预约绑定弹窗 + 密码同步

## 统一登录页改造 (`pages/login/index.js`)
- `doLogin()` 先尝试客户端登录，401 后尝试美甲师端登录
- `_afterAuth(res, role)` 根据 `roles` 数组优先跳转美甲师端
- 注册入口链接指向 `/pages/register/index`

## 统一注册页 (`pages/register/index`) 新增
- 邀请码/链接/激活密钥自动识别（`parseInviteInput`）
- 邀请码实时验证（调用 `findTechByInviteCode`，显示美甲师名称或错误提示）
- 三种注册模式：邀请码→客户端+绑定、激活密钥→美甲师、无→纯客户端

## 后端改动
- `register-by-invite.dto.ts`: `inviteCode` 从必填改为可选
- `registerByInvite()`: 无邀请码时创建纯客户端（无绑定），返回 `needsOnboarding: true`
- `activateTechnician()`: 优先复用客户端密码（而非生成随机密码）
- `client-auth login()`: 登录时双向同步密码（美甲师密码覆盖客户端密码）
- `technician-auth login()`: 登录时双向同步密码（客户端密码覆盖美甲师密码）

## 预约强制绑定美甲师弹窗
- `create-order/index.js`: `loadTechnicians()` 无绑定时弹出 `showBindTech` 弹窗
- 支持邀请码/链接输入及实时验证
- 绑定成功后重新加载美甲师列表
