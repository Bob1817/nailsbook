## 1. 背景与产品定位

### 1.1 业务背景
OnlyNail 微信小程序已正式上线。在真实使用中，小程序端非常适合美甲师处理**随身、高频、轻量**的业务动作（如：接单确认、查看客户甲型与禁忌提醒、快捷报价、日常日程管理），但在以下**重输入、批量处理、宽屏复盘**场景中存在明显效率瓶颈：
1. **作品上传与管理繁琐**：相机/修图软件导出的原图常在电脑或 iPad 中整理，在手机小程序里逐张选图、裁图、填写标签（色系/甲型/工艺/风格/定价）效率低，且缺乏批量操作能力。
2. **经营数据看不全**：手机屏幕受限，难以同屏对比不同款式的曝光、收藏、分享、预约转化表现及月度营收趋势。
3. **客户档案整理不便**：在桌面端宽屏环境下批量整理客户标签、回顾客户历史款式时间轴与复购周期，效率远高于手机端。

### 1.2 产品定位与红线
- **核心定位**：定位为独立美甲师 / 主理人的**桌面端「创作者工作台（Creator Studio）」**（对标小红书创作者中心的产品形态），而非传统实体门店多员工 ERP 或中心化电商后台。
- **双端职责边界**：
  - **微信小程序（随身工作台）**：实时接单、快捷报价、日程管理、消息沟通、到店服务禁忌提醒。
  - **Web 创作者中心（桌面工作台）**：批量发作品、作品集精修与排期、经营数据分析、客户档案深度整理、个人 IP 主页装修。
- **严禁偏离**：不引入多员工考勤/提成排班、门店收银台、平台竞价广告等与「独立手艺人」定位相悖的逻辑。

## 4. 功能需求详述

### 模块一：登录与账号体系（P0）

1. **微信小程序扫码登录（核心推荐方式）**
   - 登录页默认展示小程序扫码登录二维码，美甲师使用已登录的「OnlyNail 微信小程序」扫码并确认即可登录 Web 端，无需记忆密码。
   - 二维码状态机：`待扫码` → `已扫码待确认` → `登录成功` / `已过期（点击刷新）`。
2. **手机号 + 密码 / 短信验证码登录（保留兜底）**
   - 复用现有 `/technician/auth/login` 与忘记密码重置流程，兼容已设置密码的美甲师。
3. **权限与状态校验**
   - 仅允许已认证/非游客态的美甲师账号进入（复用 `TechnicianJwtAuthGuard` 与 `TouristGuard`）。

---

### 模块二：创作首页概览（P0）

进站首屏，参考小红书创作者中心首页，聚焦「今日经营状态 + 作品转化表现 + 快捷创作入口」：

1. **顶部快捷创作区**
   - 醒目的「发布新作品」主按钮，支持直接拖拽图片文件到卡片区域触发上传流程。
2. **核心数据看板（支持按本月 / 近 7 天 / 近 30 天切换）**
   - **经营指标**：本月已完成订单数、确认营收金额、客单价、老客复购率。
   - **作品指标**：在架作品总数、总浏览量、总收藏/点赞数、分享引流咨询数。
3. **趋势图表区**
   - 近 30 天「预约量 / 营收」折线趋势图。
   - 作品分享获客漏斗图（浏览 → 收藏 → 发起快捷报价/预约 → 成交）。
4. **待办与草稿提醒**
   - 待发布草稿数量（点击直达草稿箱）。
   - 审核未通过/需修改的作品提醒。

---

### 模块三：作品工坊 / 作品管理（P0，核心痛点）

彻底解决小程序端传图慢、整理难的问题：

1. **桌面端增强发布器（支持新建与编辑）**
   - **拖拽多图上传**：支持本地多张图片拖拽上传，支持拖拽调整图片顺序、设置封面图、基础裁剪/旋转（4:3 或 3:4 规范比例提示）。
   - **自动压缩与预览**：前端上传前按规范压缩大图，右侧提供**「小程序端展示效果实时预览」**（所见即所得）。
   - **结构化信息录入**：
     - 作品标题、款式说明、穿搭/肤色建议（已有字段）。
     - 价格信息（基础价 / 区间价 / 关联服务项目）。
     - **标签体系**：一键点选预设标签模板（色系、甲型、风格、工艺、季节），支持自定义新增并沉淀到模板库。
     - **制作方案与用料备注**（仅美甲师自己可见，方便后续复刻）。
     - **客户关联与授权**：支持关联历史订单/客户（已有 `access-options` 能力）。
   - **一键复用模板**：支持「复制为新作品」或「复用上一条作品的标签与价格」，适合同系列多色号批量上新。
2. **作品列表与多维筛选**
   - 状态 Tab：`全部` / `已上架` / `已隐藏` / `草稿箱` / `审核中/未通过`。
   - 筛选与搜索：按关键词、标签、价格区间、是否置顶/精选、创建时间排序。
   - 列表视图切换：支持**卡片网格视图**（看图方便）与**表格视图**（看数据、改价格、批量操作方便）。
3. **批量管理能力（Web 端核心增量）**
   - 支持多选作品进行：**批量上架/隐藏**、**批量打标签/移除标签**、**批量调整价格**、**批量删除**。
   - 单条快捷操作：一键置顶、设为精选、开启/关闭推广、生成小程序分享码预览。
4. **主页主推位管理（Hero Recommendations）**
   - 可视化拖拽排序小程序主页顶部推荐作品位（复用现有 `hero-recommendations` 接口）。

---

### 模块四：数据中心（P1）

将后台沉淀的交易与行为数据转化为美甲师看得懂的经营建议：

1. **作品表现排行榜**
   - 按浏览量、收藏数、分享引流数、带来预约订单数排行，直观识别「爆款引流款」与「高转化成交款」。
   - 支持按时间范围（近 7 天 / 近 30 天 / 指定月份）筛选。
2. **转化漏斗分析**
   - 展示作品分享链路转化率（分享曝光 → 详情访问 → 发起报价/预约 → 订单完成）。
3. **经营与客户复盘**
   - 营收构成（新客 vs. 老客占比）、服务时段分布（工作日 vs. 周末热力分布）、客户生命周期分布（新客 / 活跃复购 / 沉睡待唤醒）。
   - 支持按自然月查看历史月报（复用 `technician/insights/overview?month=YYYY-MM`）。

---

### 模块五：客户档案工作台（P1）

利用电脑大屏高效维护专属客户资产（非实时客服聊天，专注档案沉淀）：

1. **客户宽屏列表**
   - 展示客户昵称、备注名、标签、累计消费次数、累计消费金额、最近到店时间、生命周期状态。
   - 支持按关键词、客户标签、生命周期状态、消费频次筛选排序。
2. **客户详情全景抽屉（右侧抽屉或分栏）**
   - **重点避坑信息置顶**：甲型特征、偏好色系、过敏/敏感禁忌（与小程序端预约高亮提醒同步）。
   - **历史服务与作品时间轴**：按时间倒序展示该客户每次做过的款式图片、实际成交价、服务备注。
   - **跟进记录**：记录回访/提醒事项。
3. **标签模板管理**
   - 集中管理「客户标签模板」与「作品标签模板」（复用 `tag-templates` 接口），支持批量为筛选出的客户打标。

---

### 模块六：主页与服务规则快捷配置（P2）

作为辅助管理入口，方便在电脑上一次性完善大段文案与服务价目表：
- **个人 IP 资料**：主理人昵称、简介、工作室地址/环境图、资质证书展示。
- **服务项目与阶梯定价**：增删改服务项目、加价项规则、上门服务规则设置。

## 6. 非功能性需求与部署约束

1. **图片上传体验与存储**：支持常见格式（JPG/PNG/WebP），单次支持最多 20 张图片并发队列上传并展示进度条；大文件前端压缩后上传，避免占用过多带宽。
2. **交互与可用性**：核心列表操作支持键盘快捷键（如 `Esc` 关闭抽屉）、表单未保存离开提醒（防止长文案编辑丢失）。
3. **部署规范**：沿用 [docker-compose.yml](file:///Users/shibo/Documents/Codex/nailBook/docker-compose.yml) 中 `tech-web` 服务（48MB 内存限制的静态 Nginx 容器），通过 GitHub Actions 构建镜像后部署至 ECS，不影响当前 `backend` 与 `admin-web` 运行稳定性。
