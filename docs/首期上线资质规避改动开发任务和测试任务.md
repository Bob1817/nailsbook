```
Step 1: DEV-01 (app.json)          ← 必须最先，其他任务依赖
         ↓
Step 2: DEV-02 + DEV-03 (创建预约)  ┐
        DEV-04 + DEV-05 (订单状态)  ├─ 可并行
        DEV-06 (订阅去价格化)       │
        DEV-07 (后端 flag)         ┘
         ↓

        DEV-11 (客户端我的页)                ├─ 可并行
         ↓
Step 4: QA-01 (编译测试) → QA-02 ~ QA-07 (功能) → QA-08 (回归) → QA-09 + QA-10 (合规)
```
