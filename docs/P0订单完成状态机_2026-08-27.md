# P0 订单完成状态机与接口契约

本文件记录代码实现，不代表产品负责人已经签字。保留现有定时自动开始/完成规则，未新增客户二次确认完成环节。

## 状态转移

| 前置状态 | 合法目标状态 | 主要操作者/入口 |
| --- | --- | --- |
| pending_quote | pending_agree、cancelled、expired | 美甲师报价、取消、系统过期 |
| pending_agree | pending_confirm、pending_quote、cancelled、expired | 客户同意/拒绝报价、取消、系统过期 |
| pending_client_confirm | pending_confirm、cancelled、expired | 客户确认、取消、系统过期 |
| pending_confirm | pending_home、pending_shop、cancelled、expired | 美甲师确认接单、取消、系统过期 |
| pending_home / pending_shop | in_progress、cancelled | 系统按预约开始时间推进、取消 |
| in_progress | completed、cancelled | 美甲师提交完成资料，或系统到预约结束时间自动完成 |
| expired | pending_quote、pending_agree、pending_confirm、pending_client_confirm | 重新发起，按原流程恢复 |
| completed / cancelled | 无 | 终态；不得再次完成 |

具体权限、业务前置条件仍由对应接口校验；此表不是允许客户端任意设置状态的接口。

## 完成与作品接口

| 接口 | 前置条件 | 成功结果 | 重复/失败 |
| --- | --- | --- | --- |
| PATCH /api/technician/orders/:id/complete | 本人订单、in_progress；金额非负、时间成对且结束晚于开始 | 订单 completed；服务记录、客户统计、收入、售后任务同一事务写入 | 重复/非法状态/不完整时间 400；他人订单 403；不存在 404；数据库失败回滚 |
| 系统每 5 分钟自动完成 | in_progress 且预约结束时间已到 | 调用与人工完成相同的事务，收入仍为 confirmed | 并发抢占失败不重复累计；异常记录日志，后续扫描重试 |
| POST /api/technician/works/from-order/:orderId | 本人已完成订单 | 获取或创建唯一 sourceOrderId 草稿，带照片、金额、客户/订单关联 | 并发和后续重试返回同一作品；他人/未完成订单 404 |
| PATCH /api/technician/works/:id | 本人作品，字段合法 | 保存编辑并进入既有审核流程 | 保存失败不影响已完成的订单；不是再次完成服务 |
| PUT /api/technician/works/:id/access | 本人作品，客户/订单归属合法 | 原子更新授权范围和授权客户 | 不合法关联拒绝；不能跨美甲师授权 |

完成接口返回的是 **Revenue**，其中 `status: confirmed` 是收入状态；订单状态应读取订单详情或数据库中的 `completed`。原测试的 `pending` 期望与既有实现不一致。本次保留收入语义，并增加订单、记录、收入及事务回滚断言。

## 数据与界面约束

- 订单详情“完成服务”进入 complete-service，携带订单 ID；金额优先已有实际金额/报价，部分定金不能替代最终服务金额。
- 完成资料保存失败保持表单，解除提交锁；成功后禁止重复提交。返回订单使用 navigateBack(delta: 1)。
- “发布关联作品”先获取订单唯一草稿，再编辑该草稿 ID；重复点击不创建多份作品。
- 客户照片通过既有 client-photos 接口保存到订单，不把照片或授权塞入 CompleteServiceDto。草稿优先继承 clientPhotos，否则继承 customImages。
- 新草稿默认 draft、isVisible=false、authorized_clients、公开授权 pending，客户关联默认不可分享。完成订单或创建草稿不等于客户同意公开照片。
- 自动完成与人工完成现在共用事务，自动完成仍按原规则采用已有实际金额或报价减优惠。是否保留“到预约结束时间自动完成”须由产品最终确认；本次没有擅自关闭该规则。
- 评审修复：自动模式不改写实际收款或支付状态，客户累计实收仅累计已有收款；未传材料成本时保留原值。人工提交实际金额的既有语义保持不变。自动/人工模式是服务端内部参数，不接受客户端选择。
- 草稿进入待审核状态必须通过套餐作品额度检查；已占额度作品的普通编辑不重复占用额度。编辑页使用 imageUrls 加载照片并在保存时完整写回 images JSON。
