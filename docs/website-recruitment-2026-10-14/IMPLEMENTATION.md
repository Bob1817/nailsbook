# 官网邀请入驻改造实施记录

日期：2026-10-14。范围：官网首版改造及必要的入驻申请接口修复；未部署、未提交或推送代码。

## 已落实

- 移动优先的中英文官网：目标人群、三个经营场景、可切换流程示意、邀请政策、开通步骤、FAQ 与申请入口。
- 统一政策：邀请体验期免费，后续收费另行通知；不编造体验时长或未来价格。
- NailBook 微信公众号承接咨询，提供二维码、保存图片与复制名称；关注不是申请条件。
- 首页增加独立的小程序引导：直接展示 OnlyNail 小程序码、微信搜索名和三步体验说明，并明确浏览体验不会自动提交入驻申请，美甲师管理端需获邀后开通。
- 申请页保留核心字段，服务方式固定选择，补充信息折叠；提供校验、重复点击保护、超时、失败重试与成功说明。
- 申请信息说明页及真实联系入口，移除原无实际提交能力的咨询表单。
- 后端校验、SQLite 原子防重复申请、旧服务方式兼容；旧手机号查询不再公开申请状态。
- 旧产品截图替换为明确标注的流程示意，不将示例视为真实客户数据。

## P0 / P1 响应式补强（2026-10-15）

- 移除根节点 320px 最小宽度限制，并为 319px 以下视口收紧容器留白、卡片内边距和 CTA 排版。
- 视口声明增加 `viewport-fit=cover`；页头、内容容器、页脚、固定 CTA 与扫码弹窗接入四向安全区变量。
- 首页固定入驻 CTA 改为主视觉离开视口后出现；打开扫码弹窗时自动隐藏，避免与首屏按钮和弹窗操作重叠。
- 增加 `horizontal-viewport-segments: 2` 渐进增强：双栏、内容卡片、固定 CTA 与扫码弹窗根据左右视口分段排列，并将铰链区域留作间距。普通浏览器不支持该媒体查询时继续使用原响应式布局。

验证结果：

- 280 × 653：`documentElement.scrollWidth` 与 `innerWidth` 均为 280px，无横向溢出；首屏 CTA 数量为 0，离开主视觉后为 1。
- 280 × 653 扫码弹窗：弹窗完整显示，打开时固定 CTA 数量为 0。
- 390 × 844：无横向溢出，当前视口可见交互控件高度均不低于 44px。
- 768 × 900：主视觉保持双栏，无横向溢出。
- 官网 Vitest 3 个测试文件、11 项通过；生产构建、颜色同步检查与颜色规范检查通过。
- 物理折叠屏的铰链环境变量无法由普通浏览器宽度模拟，本轮完成了源码与构建验证，仍需在支持双视口分段的真机或模拟器上做发布前复核。
