# 高端美甲师个人品牌主页 - 需求计划

> 版本：v1.0  
> 更新时间：2026-08-18  
> 产品定位：高端美甲师个人品牌展示平台

---

## 一、产品定位与核心理念

### 1.1 产品定位
- **不是**普通美甲师预约平台
- **而是**高端美甲艺术家个人品牌展示平台
- 每个美甲师都有独立IP和差异化优势
- 通过专业背书建立信任，支撑溢价

### 1.2 核心信任公式
```
信任 = 专业资质 + 作品证明 + 客户评价 + 社交数据
溢价 = 信任 × 审美价值
```

### 8.2 新增 TechnicianQualification 表

```sql
CREATE TABLE TechnicianQualification (
  id SERIAL PRIMARY KEY,
  technicianId INTEGER NOT NULL REFERENCES Technician(id),
  type VARCHAR(20) NOT NULL,  -- education/training/certificate/certification/award
  title VARCHAR(100) NOT NULL,
  detail VARCHAR(200) NOT NULL,
  organization VARCHAR(100),
  year INTEGER NOT NULL,
  month INTEGER,
  imageUrl VARCHAR(500),
  isVerified BOOLEAN DEFAULT FALSE,
  sortOrder INTEGER DEFAULT 0,
  createdAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updatedAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 8.3 新增 TechnicianFeaturedComment 表

```sql
CREATE TABLE TechnicianFeaturedComment (
  id SERIAL PRIMARY KEY,
  technicianId INTEGER NOT NULL REFERENCES Technician(id),
  commentId INTEGER NOT NULL REFERENCES Comment(id),
  sortOrder INTEGER DEFAULT 0,
  createdAt TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(technicianId, commentId)
);
```
