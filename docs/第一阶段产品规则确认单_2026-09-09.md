# NailBook 第一阶段产品规则确认单

> 日期：2026-09-09<br>
> 状态：待产品负责人确认<br>
> 适用版本：第一阶段微信小程序上线候选版本

本文只确认第一阶段必须稳定的业务规则。确认后，前端文案、后端校验、测试用例和运营说明均以本文为准。

## 1. 首发范围

- 发布微信小程序、后端 API 和超管后台。
- 微信小程序同时承载客户与美甲师角色，一个微信用户可以拥有其中一个或两个角色。
- 首发仅服务指定门店的到店美甲预约，不开放上门服务、第三方商户自由入驻和平台交易撮合。
- 首发不开放微信在线支付。总价、定金及是否已收款用于双方确认和经营记录，实际付款在线下完成。
- Client Web、Technician Web、Flutter 和原生 iOS 不随本次上线，但其构建不得被共享代码改动破坏。

## 2. 账号、角色与会话

1. 仅有客户角色的账号进入客户首页；仅有美甲师角色的账号进入美甲师首页。
2. 同时拥有两个角色时，用户可以在“我的 → 账号与设置 → 切换角色”中直接切换。
3. 账号名称后仅在当前身份为美甲师时展示“美甲师”角色标识；客户身份不展示额外角色标签。
4. “切换角色”“切换账号”“退出登录”是同级操作：
   - 切换角色保留同一用户的双角色登录信息并进入目标角色首页。
   - 切换账号清除当前账号会话并返回登录入口。
   - 退出登录清除客户、美甲师及刷新令牌，不保留可直接进入业务页的旧会话。
5. 每次请求优先使用当前角色令牌；客户令牌、美甲师令牌和管理员令牌不能跨角色访问。
6. 访问令牌过期时只允许一次刷新；刷新失败才退出。普通网络故障不主动删除仍有效的本地会话。

## 3. 客户绑定美甲师

1. 每名客户最多占用 5 个美甲师绑定名额，已绑定和待审核申请共同计数。
2. 重复申请同一美甲师不重复占用名额；待审核转正式绑定也不再次占用。
3. 既有历史账号超过 5 个绑定时不自动解绑，但在降到 5 个以内前不能继续新增。
4. 客户“我的”页面只展示前 2 位已绑定美甲师，同时显示已绑定数量和待审核数量。
5. 全部美甲师、默认美甲师、待审核状态、解绑及继续绑定统一在“我的美甲师”页面管理。
6. 解绑默认美甲师后，系统选择另一位有效绑定作为默认；没有剩余绑定时清空默认美甲师。

## 4. 作品发布与审核

1. 新建作品先保存为草稿或提交审核，只有 `publicationStatus=approved` 才显示“已发布”。
2. 作品公开访问必须同时满足：
   - 美甲师账号有效；
   - 作品审核通过；
   - 作品已显示；
   - 未归档；
   - 公开作品还必须设置为公开范围。
3. 待审核、审核拒绝、隐藏、私密或归档作品不能通过公开作品接口访问。
4. 编辑已发布作品时，如修改内容需要重新审核，则作品重新进入待审核并暂时退出公开展示。
5. 超管后台提供待审核、已通过、已拒绝列表，并支持查看作品内容、通过和拒绝；拒绝必须填写可供美甲师理解的原因。
6. 美甲师可以显示/隐藏、置顶/取消置顶、加入/移出主页精选、编辑和删除自己的作品。
7. 删除作品是不可恢复操作，必须二次确认；隐藏作品保留数据，可以再次显示。

## 5. 客户首页 Hero 推荐

1. 每位美甲师最多设置 3 个客户首页推荐作品，与个人主页精选的 6 个名额互相独立。
2. 只有本人公开、审核通过、已显示、未归档且有封面的作品可以进入 Hero 推荐。
3. 未满 3 个时，从作品操作菜单点击“推荐至客户首页”后直接推荐成功。
4. 已满 3 个时，展示当前推荐作品；用户选择要被替换的作品并确认后完成替换。
5. 已推荐作品的菜单显示“取消客户首页推荐”，确认后直接取消。
6. 作品隐藏、转为私密、重新进入审核、归档或失去封面时，系统自动释放其推荐位。
7. 客户首页最多展示 5 个 Hero 作品：默认美甲师优先，其余按绑定时间倒序；先从每位美甲师取 1 个，再进入下一轮，同一美甲师最多贡献 3 个。
8. 无合格推荐作品的美甲师自动跳过；只有一个作品时不自动轮播。

## 6. 预约、报价、排期与定金

### 6.1 标准服务预约

1. 客户选择美甲师、服务、门店和时间后提交预约申请。
2. 提交只是申请，美甲师确认前不视为正式占用；重复点击或网络重试不得生成重复订单。
3. 美甲师在“确认排期与报价”中必须核对并可修改：
   - 最终总价，必须大于 0、不超过 100 万元且最多两位小数；
   - 定金金额，必须在 0 到最终总价之间且最多两位小数；
   - 定金是否已实际支付。
4. 定金为 0 时自动视为无需定金，不能标记“定金已支付”。
5. 只有美甲师已实际收到线下定金时才开启“定金已支付”。确认结果写入订单、交易记录和双方详情。
6. 确认排期成功后进入“待到店”；时间冲突时确认失败且原订单数据不被部分修改。

### 6.2 自定义需求

1. 客户提交需求后进入“待报价”。
2. 美甲师发送包含日期、时间、时长、服务项目、最终价格和定金的报价后，进入“待用户确认”。
3. 客户接受后进入“待我确认”，由美甲师最终确认排期；客户拒绝后不得自动确认订单。
4. 美甲师重新报价时，以最新报价为准，旧报价不得被客户重复接受。

### 6.3 状态与操作

| 状态 | 面向用户的含义 | 美甲师主要操作 | 客户主要操作 |
|---|---|---|---|
| 待报价 | 客户已提交自定义需求 | 发送报价、取消 | 查看、取消 |
| 待用户确认 | 美甲师已发送报价 | 等待、取消 | 接受、拒绝、取消 |
| 待我确认 | 客户已同意或提交标准预约 | 调整报价、确认排期、取消 | 查看、取消 |
| 待到店 | 双方已确认到店时间 | 取消；到时进入服务中 | 查看、按规则取消 |
| 进行中 | 服务已经开始 | 完成服务 | 查看 |
| 已完成 | 服务资料和收入已落账 | 查看、发布关联作品 | 查看、评价 |
| 已取消/已拒绝/已过期 | 预约不再履行 | 查看 | 查看 |

5. 取消后双方状态必须一致并释放档期；定金处置按取消确认结果记为退款或不退。
6. 完成服务必须保存实际时间、金额及服务记录；订单、收入、客户统计在同一事务中更新。
7. 重复完成、越权完成或已取消订单完成必须失败，且不能产生重复收入或关联作品。

## 7. 首发关闭能力

- 所有上门服务入口、定位和上门地址能力在首发模式中不可用。
- 微信支付、线上退款和平台代收款入口保持关闭。
- 未配置或未获批的订阅消息不得显示为已启用。
- AI 图片、营销扩展等非核心能力出现服务不可用时，不得阻断登录、作品、预约和订单主链路。
