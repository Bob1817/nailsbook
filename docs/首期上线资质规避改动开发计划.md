# NailBook 首期上线资质规避改动开发计划

**文档版本：v1.0**
**编写日期：2026-08-19**
**关联需求：** [首期上线资质规避改动需求文档](./首期上线资质规避改动需求文档.md)
**状态：待评审**

> **历史文档提示：** 本计划仅覆盖早期的上门、订阅展示和支付入口调整，已被 [微信小程序首期合规上线开发计划 v2](./微信小程序首期合规上线开发计划_v2.md) 取代，不得单独作为开发或发布依据。

## 一、计划概述

### 1.1 开发范围

本计划基于需求文档中的三项 P0 需求（REQ-01 上门服务移除、REQ-02 订阅去价格化、REQ-03 定金/尾款线下化），拆解为可执行的开发阶段。所有改动限于 `client-wxapp`（微信小程序端），不涉及后端 API 破坏性改动。

### 1.2 阶段划分

| 阶段 | 名称 | 目标 | 包含需求 | 预估工时 |
|------|------|------|---------|---------|
| Phase 0 | 基础配置移除 | 移除页面注册和权限声明 | REQ-01-4 | 0.5h |
| Phase 1 | 客户端核心改动 | 创建预约页 + 订单状态 | REQ-01-1, REQ-01-2 | 4h |
| Phase 2 | 订阅去价格化 | 订阅页展示层改动 | REQ-02 | 1h |
| Phase 3 | 支付线下化 | 后端 flag 配置 | REQ-03 | 0.5h |
| Phase 4 | 美甲师端 UI 清理 | 美甲师端上门设置移除 | REQ-01-5, REQ-01-6 | 2h |
| Phase 5 | 客户端 UI 清理 | 我的页上门标签/地址入口移除 | REQ-01-3 | 1h |
| Phase 6 | 全量验证 | 构建测试 + 合规验收 | — | 2h |
| **合计** | | | | **11h** |

### 1.3 依赖关系

```
Phase 0 (app.json 配置) ─┬─→ Phase 1 (创建预约页 + 订单状态)
                         ├─→ Phase 2 (订阅去价格化) [独立]
                         ├─→ Phase 3 (支付 flag) [独立]
                         ├─→ Phase 4 (美甲师端 UI)
                         └─→ Phase 5 (客户端 UI)
                                    ↓
                              Phase 6 (全量验证)
```

> Phase 1/2/3/4/5 之间无强依赖，可并行推进。Phase 6 须在所有改动完成后执行。

## 二、详细开发阶段

### Phase 0：基础配置移除（REQ-01-4）

**目标：** 移除 `app.json` 中上门服务相关页面注册和地理位置权限声明

| 任务 | 文件 | 具体操作 | 验收标准 |
|------|------|---------|---------|
| 0.1 移除页面注册 | `client-wxapp/app.json` | 从 `pages` 数组移除 `addresses`、`address-edit`、`home-service-settings` | 小程序启动正常，无缺失页面警告 |
| 0.2 移除位置权限 | `client-wxapp/app.json` | 移除 `requiredPrivateInfos: ["chooseLocation"]` 和 `permission.scope.userLocation` | 微信开发者工具中无位置权限申请提示 |

**前置条件：** 无
**风险：** 如果有页面通过 `navigateTo` 跳转到已移除的页面，会产生跳转失败。需在 Phase 1/4/5 中同步移除对应的跳转代码。

| 1A.2 移除地址加载 | `create-order/index.js` L119, L140, L187-194 | 移除 `loadAddresses()` 方法定义及所有调用点 | 无地址加载网络请求 |
